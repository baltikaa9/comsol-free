# Работа с проектами в Comsol-FreeFDD

## Функционал сохранения и открытия проектов

### Что сохраняется

При сохранении проекта в файл `.json` сохраняются:

1. **Геометрия**:
   - Линии (`LineItem`)
   - Прямоугольники (`RectangleItem`)
   - Эллипсы (`EllipseItem`)
   - Кривые Безье (`ParametricCurveItem`)
   - Булевые формы (`BooleanShapeItem`)

2. **Граничные условия**:
   - Связь рёбер с граничными условиями (inlet, wall, open)
   - Параметры граничных условий (скорости, турбулентные параметры и т.д.)

3. **Физические параметры**:
   - Материал (плотность, вязкость)
   - Начальные условия (скорости, давление, турбулентные параметры)
   - Модель турбулентности (Laminar, SST, k-epsilon)

### Формат файла проекта

Файл проекта сохраняется в обычном JSON формате с расширением `.json`:

```json
{
  "physics": {
    "material": {
      "rho": 1.204,
      "mu": 1.81397e-05
    },
    "initial_conditions": {
      "u": 0,
      "v": 0,
      "p": 0
    },
    "boundary_conditions": [],
    "turbulence_model": "Laminar"
  },
  "geometry": {
    "items": [
      {
        "type": "rectangle",
        "x": 100,
        "y": 100,
        "width": 200,
        "height": 150
      }
    ],
    "edges": [
      {
        "id": 1,
        "boundary_condition": {
          "type": "inlet",
          "u": 1.0,
          "v": 0.5
        }
      }
    ]
  }
}
```

### Как использовать

1. **Сохранить проект**: `Сохранить проект` (Ctrl+S) или `Сохранить как...`
2. **Открыть проект**: `Открыть проект` (Ctrl+O)

### Файлы

- `modules/data/src/services/project_service.py` - сервис сериализации/десериализации
- `modules/data/src/main_window.py` - обновлён для поддержки работы с проектами
- `modules/data/src/ui/template.ui` - добавлены действия для сохранения/открытия

### Примечания

- Используется стандартный JSON формат (не свой формат)
- Расширение файла: `.json`
- При загрузке проекта текущая сцена очищается
- Все граничные условия восстанавливаются автоматически
- Поддерживается открытие проектов из других папок
